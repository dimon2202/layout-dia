# AIR — Creative Agency Landing Page

A modern, responsive landing page for **AIR**, a creative digital agency focused on branding, communication, business strategy, and digital marketing.

The website presents the agency's expertise, services, client testimonials, and contact information through a clean, visually engaging interface.

## Preview

[**Live Demo**](https://dimon2202.github.io/layout-dia/) · [**GitHub Repository**](https://github.com/dimon2202/layout-dia)

## Features

- **Responsive Design** — Optimized layouts for desktop, tablet, and mobile devices.
- **Modern UI** — Clean and minimal visual design with a strong focus on typography and visual presentation.
- **Agency Overview** — Dedicated sections introducing the agency, its philosophy, and expertise.
- **Services Showcase** — Structured presentation of creative, marketing, and communication services.
- **Client Testimonials** — Customer feedback and testimonials to build trust and credibility.
- **Contact Section** — Contact information, social media links, and a message form.
- **Smooth Navigation** — Anchor-based navigation between website sections.
- **SCSS Architecture** — Modular and maintainable styling.

## Website Sections

- **Hero** — Main introduction and agency positioning.
- **About Us** — Agency philosophy, approach, and vision.
- **Our Expertise** — Branding, communication, and business strategy.
- **Services** — Overview of the agency's creative and marketing services.
- **Testimonials** — Client feedback and reviews.
- **Contact Us** — Contact form, phone number, location, and social media links.

## Getting Started

### Prerequisites

- Node.js
- npm or Yarn

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd <project-directory>
```

Install dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm start
```

### Production Build

Generate an optimized production build:

```bash
npm run build
```

### Code Quality

Run linters and tests:

```bash
npm test
```

Run linting only:

```bash
npm run lint
```
